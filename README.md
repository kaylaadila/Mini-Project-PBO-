# Mini Project PBO - Program Data Mahasiswa

Program sederhana berbasis Java untuk mengelola data mahasiswa dan menentukan status kelulusan berdasarkan nilai.

## 📌 Deskripsi

Program Data Mahasiswa merupakan mini project mata kuliah Pemrograman Berorientasi Objek (PBO) yang dibuat menggunakan bahasa pemrograman Java.

Program ini digunakan untuk memasukkan data mahasiswa, menampilkan informasi mahasiswa, dan menentukan status kelulusan berdasarkan nilai yang diperoleh.

## ✨ Fitur Program

- Memasukkan data mahasiswa berupa nama, NIM, dan nilai.
- Menyimpan data menggunakan objek mahasiswa.
- Menampilkan informasi setiap mahasiswa.
- Menentukan status kelulusan menggunakan percabangan `if-else`.
- Mengelola minimal 3 objek mahasiswa menggunakan perulangan.

## 💻 Konsep Java yang Digunakan

- **Variable & Data Type** — Menyimpan data mahasiswa.
- **Scanner** — Menerima input dari pengguna.
- **If-Else** — Menentukan status kelulusan.
- **Loop** — Mengulang proses input dan menampilkan data.
- **Class & Object** — Membuat dan mengelola objek mahasiswa.
- **Method** — Menampilkan data dan memeriksa kelulusan mahasiswa.

## ⌨️ Contoh Input

```text
Mahasiswa ke-1
Nama: kayla
NIM: 250810701100067
Nilai: 90

Mahasiswa ke-2
Nama: adila
NIM: 250810701100055
Nilai: 50

Mahasiswa ke-3
Nama: farija
NIM: 250810701100065
Nilai: 70
```

## 📊 Contoh Output

```text
=== DATA MAHASISWA ===

Mahasiswa ke-1
Nama: kayla
NIM: 250810701100067
Nilai: 90
Lulus

Mahasiswa ke-2
Nama: adila
NIM: 250810701100055
Nilai: 50
Tidak Lulus

Mahasiswa ke-3
Nama: farija
NIM: 250810701100065
Nilai: 70
Lulus
```

## 🎯 Logika Kelulusan

Program menggunakan percabangan `if-else` untuk menentukan status kelulusan mahasiswa berdasarkan nilai.

- Nilai >= 60: **Lulus**
- Nilai < 60: **Tidak Lulus**

## ⚙️ Cara Menjalankan Program

1. Pastikan Java Development Kit (JDK) sudah terpasang.
2. Buka terminal pada folder tempat file program disimpan.
3. Compile program menggunakan perintah:

   ```bash
   javac ProgramMahasiswa.java
   ```

4. Jalankan program menggunakan perintah:

   ```bash
   java ProgramMahasiswa
   ```
