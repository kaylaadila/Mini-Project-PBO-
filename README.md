# Mini Project PBO - Program Data Mahasiswa

## Deskripsi
Program sederhana berbasis Java untuk mengelola data mahasiswa,
menampilkan informasi mahasiswa, dan menentukan status kelulusan
berdasarkan nilai.

## Fitur
- Input data mahasiswa
- Menampilkan nama, NIM, dan nilai
- Menentukan status kelulusan
- Menggunakan perulangan untuk mengelola minimal 3 mahasiswa

## Konsep Java yang Digunakan
- Variable dan Data Type
- Scanner
- If-Else
- Loop
- Class dan Object
- Method

## Cara Menjalankan

Compile program:

javac ProgramMahasiswa.java

Jalankan program:

java ProgramMahasiswa

## Teknologi
- Java
- JDK
